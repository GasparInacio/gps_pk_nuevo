- Para instalar las dependencias primero verificar que esté activado el entorno virtual que se genera con la creacion del proyecto en pycharm, en el caso de no estar activado ingresar en la consola el siguiente comando:

    .venv/Scripts/activate

    - Se verifica que esté activado el entorno si aparece algo similar e este texto:

    (.venv) PS C:\Users\Gaspar\Desktop\gps_sospechas

- Una vez activado el entorno virtual se instalan las dependencias con el comando:

    pip install -r requirements.txt

- Una vez instaladas las dependencias verificar que las importaciones en el script no lancen errores

- Para correr el script colocar el siguiente comando en la consola:

    streamlit run script_traza.py

    IMPORTANTE: veificar que sea "script_traza.py", el archivo "script_gral.py" calcula los puntos mas cercano en base a la lista de puntos fijos y no están interpolados formando una línea. Funciona pero no es lo correcto, lo mas preciso es trazar una línea con los puntos fijos y a partir de eso buscar los puntos mas cercanos a la traza.

- El script ya toma como referencia el archivo "sarmiento.csv" de puntos fijos que se encuentra en la carpeta

- En la barra lateral se debe subir el archivo excel con las sospechas

- El excel que se suba tiene que tener una columna "Latitude" y una "Longitude" con sus respectivos valores (respetar mayúsculas y minúsculas igual que en el archivo para que no lance errores). En la carpeta hay dos archivos de ejemplo, "sospechas.xlsx" es un archivo con solo 3 puntos para probar y que no tarde tanto el procesamiento, "sospechas_sarmiento.xlsx" son los datos del archivo de las sospechas que se pasaron al grupo el día 09/10/2025 con los puntos a verificar

- La barra de progreso muestra la cantidad de puntos que van siendo procesados

- Una vez procesados todos los puntos se muestra una tabla con la vista previa de las columnas y sus respectivos valores de lo que se encontró

    - latitud y longitud buscadas, latitud y longitud mas cercana con su respectivo pk y la distancia de la sospecha al punto fijo en m

- El botón de descarga permite guardar la tabla previsualizada en formato excel.
